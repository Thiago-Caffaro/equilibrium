# Reloadable KubeJS server experiments

Place recipe, tag, and other reloadable server-data experiments here. Name a
script after one coherent hypothesis, for example
`01-create-merchant-candidate.js`, and add its inventory row before copying it
to `<test-instance>/kubejs/server_scripts`.

Use `/reload` only after verifying that the exact KubeJS event and affected
data type are reloadable for the installed version. Record the command and
result in the experiment's test-profile note. Do not implement Core offer
authority or a Merchant transaction engine in KubeJS.
