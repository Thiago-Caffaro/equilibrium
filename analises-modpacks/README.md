# Auditorias de modpacks de referência

Esta pasta preserva evidências coletadas diretamente das instâncias locais de modpacks de referência. Ela é separada do planejamento conceitual: uma observação sobre uma referência não promove um mod, uma mecânica ou uma estrutura a decisão do Equilibrium.

## Método

A auditoria segue o [protocolo de análise de modpacks](../planejamento-conceitual/11-protocolo-de-analise-de-modpacks.md): primeiro arquivos, scripts, receitas, configurações e quests; gameplay breve somente para verificar uma hipótese específica que os arquivos não resolvam.

Cada relatório deve distinguir claramente:

- **Fato observado:** presente nos arquivos da instância auditada.
- **Leitura para análise:** motivo pelo qual o fato merece atenção no Equilibrium.
- **Não concluído:** ponto que não pode ser inferido sem investigação adicional ou decisão conceitual.
